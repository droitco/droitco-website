How it works

Four simple rules.

Think of it like this: you own the lockers. We find the customer. You keep the building.

You own it
The building is yours. The renter’s lease is in your name. We never rent it as Droit.
We find the renter
We list the empty unit on GetSelfStorageNow, Google, Maps, and the same websites we already use.
Your floor price
You tell us the lowest amount you will take. We rent the unit for more than that. If we cannot, we do not take the job.
Empty units only
We only work on units that are empty. No listing fee. We get paid when someone moves in.

Where renters find us

The same places we already use.

People book online. We put your empty units where we already put ours: GetSelfStorageNow, Google, Maps, and the store websites.

Who we already do this for

We already run this at stores we manage.

We manage multiple self-storage facilities across the country. Empty units get filled the same way at each of them.
